## Русский

Профессиональная IDE для разработки на языке RbxEasy.

### 🚀 С чего начать

Этот репозиторий содержит исходный код RbxEasy IDE. Чтобы запустить или собрать проект из исходников, следуйте инструкциям ниже.

#### Требования

- [Node.js](https://nodejs.org/) (Рекомендуется: последняя LTS версия)
- npm (идет в комплекте с Node.js)

#### Установка

1. Склонируйте репозиторий или скачайте исходный код.
2. Откройте терминал в папке проекта.
3. Установите зависимости:
   ```bash
   npm install
   ```

#### Разработка

Чтобы запустить приложение в режиме разработки:
```bash
npm run dev
```

#### Сборка

Чтобы собрать готовую к использованию версию для Windows (.exe):
```bash
npm run build:win
```
Готовый установщик появится в папке `dist/`.

## English

Professional IDE for RbxEasy language development.

### 🚀 Getting Started

This repository contains the source code for RbxEasy IDE. To run or build this project from source, follow the instructions below.

#### Prerequisites

- [Node.js](https://nodejs.org/) (Recommended: Latest LTS)
- npm (Comes with Node.js)

#### Installation

1. Clone this repository or download the source code.
2. Open your terminal in the project directory.
3. Install dependencies:
   ```bash
   npm install
   ```

#### Development

To start the application in development mode:
```bash
npm run dev
```

#### Building

To build the production-ready Windows installer (.exe):
```bash
npm run build:win
```
The resulting installer will be located in the `dist/` directory.
