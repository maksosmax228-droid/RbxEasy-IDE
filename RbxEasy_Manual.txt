========================================================================
             RBXEASY LANGUAGE SPECIFICATION & MANUAL (V1.0)
========================================================================

Это официальное руководство по языку RbxEasy, созданному для упрощенной 
и эффективной разработки в среде Roblox. RbxEasy компилируется в Luau.

--- 1. ОСНОВНОЙ СИНТАКСИС ---

1.1 Переменные:
Используйте 'var' для объявления переменных. 
В итоговом коде они становятся 'local'.
Пример:
    var speed = 50
    var name = "RbxEasy"

1.2 Функции:
Используйте 'func' для объявления функций. 
Круглые скобки () ОБЯЗАТЕЛЬНЫ.
Пример:
    func start() {
        print("Запуск...")
    }

1.3 Условия и Циклы (C-style):
Поддерживаются фигурные скобки {}.
Пример:
    if x > 10 {
        print("Больше")
    }
    
    while true {
        task.wait(1)
    }

--- 2. ГИБРИДНЫЙ РЕЖИМ (БИЛИНГВАЛЬНОСТЬ) ---

RbxEasy уникален тем, что позволяет смешивать нативный Luau и RbxEasy в одном файле.

2.1 Luau-стиль:
Вы можете использовать ключевые слова Luau там, где это удобно.
Пример:
    local y = 20
    function test()
        if y == 20 then
            print("Это Luau!")
        end
    end

2.2 Логические операторы:
Поддерживаются оба стиля:
    RbxEasy: && (и), || (или), ! (не)
    Luau: and, or, not
Пример:
    if (x > 0 && !isDead) || (y == 100) { ... }

--- 3. СПЕЦИАЛЬНЫЕ ВОЗМОЖНОСТИ ---

3.1 Система инклудов (include):
Позволяет объединять несколько файлов .rbxe в один бандл.
Использование:
    include "LibraryName"
(IDE найдет LibraryName.rbxe и вставит его код в начало при сборке).

3.2 Функция listen():
Упрощенный синтаксис для подключения событий (Connect).
Пример:
    listen(game.Players.PlayerAdded, func(player) {
        print("Зашел игрок: " + player.Name)
    })

3.3 Блок сырого Luau:
Если нужно вставить кусок кода без каких-либо преобразований:
    luau {
        -- Здесь можно писать любой Luau код
        local x = game:GetService("RunService")
    }

--- 4. ЛУЧШИЕ ПРАКТИКИ ---

- Всегда используйте :WaitForChild() для доступа к объектам в Workspace.
- Используйте task.wait() вместо обычного wait().
- Пользуйтесь встроенным Линтером: он подскажет о забытых скобках или опечатках.

--- 5. ИНСТРУКЦИЯ ДЛЯ AI-АГЕНТОВ ---

При генерации кода на RbxEasy:
1. Используйте 'var' для переменных.
2. Используйте 'func' для функций и всегда ставьте ().
3. Используйте фигурные скобки {} для блоков.
4. Для конкатенации строк используйте '+', компилятор сам заменит его на '..'.
5. Всегда добавляйте вызов главной функции (start() или onload()) в конце файла.
